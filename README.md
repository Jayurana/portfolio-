# 🌐 Jagdish Girase - Portfolio Website

A modern, responsive portfolio website showcasing my skills, projects, and experience.

## 🚀 Live Demo
Open `index.html` in any browser to view the portfolio.

## ✨ Features
- **Hero Section** — Animated blob shapes with golden yellow theme
- **About Me** — Skills, bio, and resume popup
- **Projects** — Interactive project cards with hover effects
- **Contact** — Form with phone, email, and location info
- **Responsive** — Works on desktop, tablet, and mobile
- **Smooth Animations** — Scroll-triggered fade-in effects

## 🛠️ Built With
- HTML5
- CSS3 (Custom Properties, Flexbox, Grid)
- Vanilla JavaScript
- Google Fonts (Playfair Display, Inter)
